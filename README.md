Solmar — Streets of the Sun: a top-down open-world crime game in a sun-soaked coastal city. Steal cars, outrun the Solmar PD, run Rico's seven-mission story, pick up fares, and take back the city.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```

## Controls

- WASD / arrows — move and drive, Space to brake, Shift to run
- E — enter or leave a car
- Click — shoot (on foot or drive-by), H — horn
- P — pause, M — mute, R — restart
